## 执行前置

1. 真正的原 Owner 按文件或 hunk 明确签收：`FilePath`、当前 SHA256、`git diff HEAD`、所涉合同、允许接管范围、回归方式和回滚点。历史协作留言不是签收；用户授权接手新任务也不允许冒认旧代码作者核对过差异。
2. 主控只暂存真实批准并核实的范围，独立小批次 Git 提交；不可 `git add -A`、`reset`、`clean` 或从安装副本倒灌。
3. 重新核验全部源码与 `-RequireGitClosure`；需 0U/0M、真正可从干净检出复现，方能移入 `已完成/`。

Core 五份现行 SHA/状态与已通过的 53 项逻辑检查，见已完成的只读子任务 `../已完成/R13-01A-Core-只读盘点.md`。**只读盘点完成不解除本任务阻塞**。
