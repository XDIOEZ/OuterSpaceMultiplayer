# 地块独占操作：用户运行验收

需求：[地块独占操作规则](../../docs/plans/地块独占操作规则-20261021.md)。本卡只记录仍需用户执行的游戏内验收，源码实现和打包不等同于本卡通过。

- [ ] B 加载自己的基地且有己方小人时取得空闲操作槽；侧边显示 B 占用。A 同图查看只增加观察人数，任何输入均不能控制单位或改图。
- [ ] B 切到其他地块立即释放；进入太空或退出则在 180 秒后释放，期间不能被 A 投人占槽；B 及时返回取消释放。
- [ ] 空槽时 A、C 同时尝试空投小人，只有一个 UID 成功；另一运输单等待/可取消，不重复生成、丢失或扣除人员物资。赠物与只读侦查仍沿原版入口可用。
- [ ] A 占用 B 基地后，B 返回只读；B 可以切走控制自己的母舰及其他地块；A 不能操作 B 或盟友的小人，B 的 AI、炮塔、生产、治疗继续。
- [ ] 实际空投开始 600 秒行动；A 切图/进入太空/掉线不释放操作槽，重连剩余时间不重置。没有在线加载者时原生地表停止推进，房间倒计时继续；到期按已确认状态完成原有超时结算。
- [ ] 守方小人和盟友尚有可战斗者时不能搜刮；机器人不阻止资格。全部倒地后可搜刮，恢复的小人会重新阻止搜刮。运输容量与归属仍正确。
- [ ] 未击倒守军也可通过一次原版远征空手撤回己方小人；携带战利品必须满足搜刮资格；不能通过普通己方撤人、另一运输单或重复提交绕过一次撤离。
- [ ] 成功撤离或超时，先结清并保存人员、物资、伤势和冷却，再释放操作槽。续开旧档、重连和房主/客人交换观察时不能产生两个操作者或资产副本。

状态：待用户游戏内及跨机验收；本任务默认只打包，不安装。
