# 进入地块加载卡住：用户验收

来源：[修复记录](../../docs/reports/进入地块加载卡住修复-20261021.md)。用户明确要求运行验收由其执行，本轮不启动游戏或代跑测试。

- [ ] 客人同样可以查看无人地块与他人的基地；未获操作 UID 时只读，但不阻止地图加载。
