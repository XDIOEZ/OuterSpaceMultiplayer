# BUG-13 / P1 · Verifier 是等价登录密钥

- **来源：** [第三轮静态审计 BUG-13](../../docs/audits/联机MOD第三轮静态BUG审计与Agent修复交接-20261017.md)。
- **状态：** 安全设计风险已静态确认；需先明确威胁模型及旧身份迁移，未修复。
- **证据：** `CryptoData.Proof` 将 `Verifier` 的 Base64 字节直接用作 HMAC 密钥；房主知晓 Verifier 后即可生成后续挑战证明。初次 TCP 登记以明文消息发送 Verifier，且同安装身份可用于不同世界。
- **完成条件：** 设计不可被服务端校验值冒用的登录挑战/恢复流程（例如客户端私钥签名与服务端公钥），同时明确房主信任和 TCP 加密模型；测试两世界离线模拟中仅持有旧 Verifier 的一方不能证明新身份，正确凭证仍能注册、重连和恢复原 `PlayerId` 资产。
- **安全边界：** 不使用或记录真实玩家凭证、不做在线攻击；协议升级、旧存档/恢复码迁移必须经主控跨 Core/Session/Transport 审核，不得仅凭换哈希算法断言安全。
