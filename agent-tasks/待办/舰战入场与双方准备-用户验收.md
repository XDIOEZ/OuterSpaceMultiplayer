# 舰战入场与双方准备 · 用户验收

- 来源：2026-10-20 用户报告部署后战场为空/报错，并要求按钮改为准备、双方确认后一起入场；追加要求关键流程增加 Debug。
- 说明：[本轮报告](../../docs/reports/舰战入场配置与双方准备-20261020.md)。默认只打包，安装需明确指令；代码交付和编译结果不代表游戏验收，保持待办。

## 用户操作

1. 双端使用本轮相同版本，攻击、迎战后分别配置本方真实舰队。按钮应显示“准备”。
2. 仅一方准备：双方均不进入战场，已确认方保留页面并显示“已准备，等待对方”；未确认方可看到对方已准备。
3. 另一方准备：两端才一起创建战场；双方首发、后备、座驾与既有伤损正确，舰船实际生成，不再出现本轮缺战场配置错误。
4. 等待时关闭、断线、关系变化或配置超时应取消尚未开战的战斗并释放舰队，无虚假伤亡/结算；未收到房主确认时手动重试应提交同一份配置。
5. 正常操纵、后备增援、撤离与战损结算。若仍异常，保留双方日志，搜索 `[FreeWorldMultiplayer][fleet-battle]` 并按相同 battle/epoch 关联准备、授权、刷船和入场阶段。
