# 舰战静态身份与个人基线 · 用户验收

- 来源：2026-10-20 用户报告联机进入战场卡死；日志为 `battle.native` 静态对象重复层级身份，以及 guest 收到远端玩家 `ET_LuaRecords` 个人字段基线失配。
- 范围：本 MOD 的战场快照寻址与个人字段复制；保持真实战场、PlayerId 隔离及冲突保护。仅构建打包不代表运行验收，不安装或启动游戏，保持待办。

## 用户操作

1. 双端使用本轮相同版本，重新加载最后完整联机存档，双方分别配置舰队并准备后进入战场。
2. 在包含重复命名岩石的默认战场中，双方均应完成入场；同位置岩石/障碍与据点应一致，不再出现本轮“重复层级身份”。连续再战一场，确认旧场景身份不会影响新场景。
3. 房主与客人分别作为进攻方、模拟方各重复一次；双方可以正常操纵、增援、撤离，房主按真实检查点结算一次。
4. 入场前后触发任务/Lua 进度变化，双端各自进度独立且远端投影可以同步；本机拥有的个人进度不能被对方覆盖。
5. 断线重连、退出续开后再进入舰战，确认个人字段仍可正常同步。若仍报基线错误，保留双方完整日志及版本号；本轮原始日志没有字段内容，不能单凭它确认当时是哪条原生回调改变了 ET_LuaRecords。

## 完成条件

由用户完成上述游戏流程并提供结果后再关闭任务；编译、打包与源码提交不能替代双端验收。
