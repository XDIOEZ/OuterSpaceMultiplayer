[h1]FreeWorldMultiplayer — 《秩序：新曙光》实验性联机 MOD[/h1]

这是为《秩序：新曙光》（Outer Space）制作的社区联机 MOD，目标是在同一个世界里与朋友分别发展、互动与探索。

[h2]太空 / 星系联机[/h2]

玩家进入房主创建的联机世界，每人都有独立的母舰、舰队、雇员、物资与发展进度；并不是把所有人合成一个角色。同一星系的在线玩家可以看到彼此的舰队。设计包含 Steam 好友房间 / 邀请、房间号和 IP 直连，以及玩家交流、敌对舰队互动等内容；具体可用性以当前 MOD 版本和实机结果为准。

[h2]地表 / 地面联机[/h2]

玩家可以进入相同的星球地块，查看彼此基地、建筑、雇员与地面状态。这里不是每人生成一份互不相干的地图：同一地块只允许一名玩家获得操作权，其余玩家可以只读观察；操作权、资产归属和地图模拟者彼此独立。获得操作权也不能控制别人的小人或直接拿走对方资产。地图由一台获授权的电脑执行模拟，房主统一协调状态、同步与存档。地表空投、战斗、资源运输及结算遵循当前联机权限和规则。

[h2]English · Experimental multiplayer mod[/h2]

FreeWorldMultiplayer is a community multiplayer mod for Outer Space / Order: The New Dawn. Players join one shared host world while keeping their own motherships, fleets, crew, resources and progression. Players in the same star system can see each other's online fleets.

On a planet's ground map, players share the same authoritative map state. Only one player may hold the active control slot for a map at a time; others may observe. Control does not transfer ownership of anyone else's crew or inventory. A designated computer simulates a map while the host coordinates synchronization and saving.

This is a solo-developed experimental mod with very limited multiplayer testing. Bugs, desynchronization and compatibility issues are possible. Please back up important saves.

**Contributions welcome:** Report issues or submit PRs at [url=https://github.com/XDIOEZ/OuterSpaceMultiplayer]https://github.com/XDIOEZ/OuterSpaceMultiplayer[/url]. The MOD requires the game's Harmony dependency; current features are subject to version compatibility and real-world testing.
