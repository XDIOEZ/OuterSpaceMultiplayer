2026-10-15。用户授权主代理主控与整合，实际功能由子智能体开发。

| 责任 | 代码范围 | 交付内容 |
| --- | --- | --- |
| 会话与持久化代理 | `src/Core/`、`src/Session/`、`src/Game/NativeTransfers.cs` | 公共契约、真实会话、身份与权限、模拟权、袭击与运输事务、同代保存、原生运输接入 |
| 网络、入口与构建代理 | `src/Transport/`、`src/Entry/`、`package/`、`build.ps1`，以及 `src/Game/` 的 `NativeGalaxy`、`NativeTravel`、`NativeSharedWorld`、`NativeNpcProjection`、`NativeBuildingCommands` | IP/Steam 连接、收发与清理、原生 UI 和 MOD 启动、构建、银河舰队、规范地图旅行及建筑设置网关 |
| 游戏适配代理 | `src/Game/` 中上述两行以外的文件 | 实际玩家数据、地表实体与场景同步、权限、战斗保护、袭击与预占战利品 |
| 主控 | 模块契约协调、集成文档与构建产物 | 检查接口、整合修改、发回修正、执行编译打包并据实报告 |

- Project3 源码、资源、设置、Steam 游戏程序集、工坊共享依赖及其他 MOD 均不修改。用户已指定本次安装到 `Project3/mods/FreeWorldMultiplayer`，只有该 MOD 目录获准写入；Steam 更新后再迁移。
- `联机方案 V1.md` 是唯一现行需求；完整交付范围不因并行分工缩减。
- 对接契约由会话代理先定义，其他代理直接联系协调；主控不另写一套功能。
- 原生适配分文件移交：原负责人先迁移并通知接手者，再由接手者独占修改，避免多个代理同时编辑同一功能文件。
- 不运行游戏、Play Mode 或跨机联机测试；编译与打包结果单独记录。
- 旧 Steam 运行库兼容性风险不得掩盖，也不等于当前源代码开发必须停止。
