2. **B0**：Session `Authority/Commands/Networking/MultiplayerSession` 与 `BaseRules/SlowOperations`。在不改 Game 运动规则的前提下确认消息的调用链与 ACK。
3. **C0**：Game 的 `GameBridge/NativeMapReplicator/NativeWire/NativeMapLifecycle/NativeGroundPresentation`，核准 2D 实体/格子/位姿与原生 ready；**不允许从 Git 旧版覆盖现有混合源码**。
4. **C1**：Game 的 `NativeGalaxy/NativeSharedWorld/NativePlayerFleetBattle*` 等银河、舰队与战斗；对照已提交 `NativeFleetSynchronization` 和 `NativeRemoteFleetProxy`，保持舰队真实 UID、离线冻结及舰战锁。

## 4. 游戏正确性必须守住的底线

| 场景 | 正确结果 | 立即回退条件 |
| --- | --- | --- |
| 首次建房、继续世界、重连 | 玩家各自母舰、雇员、舰队、资金、科技、物资与任务独立；`WorldId + PlayerId` 稳定，联机存档与单机隔离 | 重复领取初始资产、串档、丢失原始身份 |
| 2D 同图与模拟者切换 | 同图只有一台有效模拟者，房主确认任期；另一端只展示真实角色、工作、伤害、建筑和物资 | 同图双份生产、重复 UID、旧 `AuthorityEpoch / Revision / CommitId` 写入 |
| SEED + 地图内容块 | 地形由准确生成参数重建，人物/建筑/物资仍来自权威快照；SHA 校验、ready 屏障、可靠 FIFO 有序回放 | 半张地图应用、坏缓存仍 ACK、漏字段或重复加载 |
| 舰队航行与战斗 | 房主唯一推进，客人控制自己舰队，离线冻结、不耗油，战斗锁/暂停有真实拒绝原因 | 已接受却没有可靠结果、客户端假位移、重复舰队或资产 |
| 运输、袭击、保存 | 原版运输边界、离线袭击 10 分钟/冷却 60 分钟、一次性战果；`SaveGeneration` 完整落盘与上个完整代恢复 | 物资/战利品复制、失败存档宣称成功、不同代混存 |

性能与正确性冲突时，**正确性优先**。不要通过丢弃关键可靠消息、提高内存上限、跳过原生地表 AI、提前 `IsMapReady` 或省略完整存档代来假装变快。性能 P95 来自合并的直方桶计数，旧 `[slow-operation]` 的阈值事件不能冒充总体分位数。
