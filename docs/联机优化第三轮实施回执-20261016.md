## 便携构建与日志命令

在主仓库执行：

```powershell
$pwsh = "$env:LOCALAPPDATA\CatStudio\FreeWorldMultiplayer\DevTools\PowerShell\7.5.4\pwsh.exe"

# 先确认审计输入和来源；当前严格闭包会明确拒绝
& .\tools\Audit-SourceClosure.ps1
& .\tools\Audit-SourceClosure.ps1 -VerifyReportPath .\artifacts\optimization-source-closure\audit.json
& .\tools\Audit-SourceClosure.ps1 -RequireGitClosure

# 仅构建正式三端包（无安装）
& $pwsh -NoProfile -File .\Sync-ModCopies.ps1 -Target All -BuildOnly

# 回归测试与分析器测试
dotnet run --project .\tools\OptimizationChecks\OptimizationChecks.csproj -c Release
& $pwsh -NoProfile -File .\tools\Analyze-MultiplayerDiagnostics.ps1 -SelfTest

# 双端实际游戏复测之后，分析同一次会话的两份日志
& $pwsh -NoProfile -File .\tools\Analyze-MultiplayerDiagnostics.ps1 -HostLog '房主日志路径' -GuestLog '客人日志路径' -OutFile .\artifacts\optimization-diagnostics\real-session.json
```

性能统计可用 `FWM_PROFILE=1` 或 `-fwm-profile` 显式开启。`[profile]` 的 P95 是桶上界，`map.cache.chunks` 的内容字节不等于带 JSON/Base64 开销的真实网络流量。舰队 `accepted` 表示命令成功确认，**并不证明舰队已发生物理位移**。
