# 地块独占操作实现（2026-10-21）

版本 V1.62，协议 13。需求见 [用户确认规则](../plans/地块独占操作规则-20261021.md)；流程见 [SVG](../diagrams/地块独占操作流程-20261021.svg)。旧同图多人操作和所有者上线抢回操作权的行为由本次规则替代。

## 实现

- `MapRecord` / `MapAccess` 加入 `OperatorPlayerId`，普通释放记录 `OperatorReleaseAtRoomSeconds`。稳定玩家 UID 继续使用现有 PlayerId，不用昵称、连接号或临时模拟者代替。Owner、Operator、Simulator 各自承担资产归属、玩家输入、原生模拟职责。
- `GroundOperationSlots` 管理空槽取得、切地表立即释放、太空/母舰/退出 180 秒宽限、回图取消宽限、战斗锁定和保存成功后的重开。加载自有基地及有己方留守人员的地块可取得空槽；不抢他人槽。
- 房主检查原生运输出发和实际到达；在途不占槽，到达别人占用的地块不落人，保留同一运输单等待/取消。纯赠物与查看不占操作槽。敌对地面行动不再以基地所有者下线为条件。
- 实际落仓记录 `GroundLandedAtRoomSeconds`；新场固定 600 秒，Loading、掉线、重连、切图不重新开始。友好/中立落人不自动建立战斗；后续实际交火沿原落仓时刻。旧存档已登记行动保留原 Duration / Elapsed。
- 命令路由、模拟者接令、HasPermission、基地创建/废弃、地面人员运输均使用操作槽门禁。原生图纸、工作指令和人员管理直接写 Bean 的入口也加玩家意图守卫；房主无操作豁免。
- `NativeCommands.IsPlayerIntent` 区分玩家意图与自动行为；AI 防御、生产、治疗/手术只由唯一 Simulator 继续运行，不用观战者 UID 代替执行角色的归属。
- 搜刮即时重新检查基地防守人类及双向友好盟友，机器人不计。倒地标记在原生人员恢复后移除；不能缓存一次胜利而忽略恢复后的守军。
- 本场带人原版远征统一进入唯一撤离事务；没有战利品也消耗机会，普通 DepartTransfer 不可绕过。玩家可未获搜刮资格而仅撤回己方人员；受保护物资仍需守军条件、实际运力和一次可靠结算。
- 结算失败保留阻塞。结算完成到可靠保存之间由 `pendingGroundSettlements` 阻止下一场取得/操作/落人，保存成功再开放。
- 侧边 UI 接入原版 `ExpeditionInfo_ABase` 的 `Status/Grid`，显示操作占用者、在线只读观察人数和本机权限。未登记地块显示待同步；名字按字面文本处理，不作为翻译键。新建与全局设置的本场时限固定显示 10 分钟。
- `ground-slot` 日志仅记录获取、宽限、释放、忙槽拒绝及结算保存状态变化。Entry 生命周期按房主政策执行太空宽限后的真实原生卸载，保留已确认的数据。
