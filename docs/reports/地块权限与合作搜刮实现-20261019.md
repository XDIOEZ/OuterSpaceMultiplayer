# 地块权限与合作搜刮实现

日期：2026-10-19。版本：V1.50；程序集：1.50.0.0；联机协议：10。

需求：[地块权限与合作搜刮规则](../plans/地块权限与合作搜刮规则-20261019.md)。流程：[SVG](../diagrams/地块权限与合作搜刮.svg)。

## 已接入的功能

| 范围 | 实现行为 |
| --- | --- |
| 中立资源 | 公共物品及本人储存物正常拿取、搬运和运输；他人实际储存区/箱中物品进入保护判断，不因友好自动开放 |
| 区域与工作 | 区域/任务仅创建者可管理；友好不再授予协作劳动，工作台仅所属玩家雇员使用；保留单向友好救助和协助战斗 |
| 储存配额 | 每玩家、每中立地块、每原生储存类型最多 3 区、合计 270 格；创建和扩绘在实际改动前限制；旧超限区保留并允许缩减 |
| 地块认领 | 其他玩家仍有本地活动雇员时阻止建立基地，友好、中立、敌对均阻止；未知驻守状态不按无人处理 |
| 基地转中立 | 原版地块面板接入本人正式/分基地转中立确认；保留区域和创建者；正式基地资格释放后，下次创建基地取得该资格 |
| 共同搜刮 | 中立地块当前活动玩家须两两双向友好；仍有活动雇员的队友储存物保持保护；基地所属者仍有活动守军时受保护 |
| 运输与归属 | 同场共用实际已落地出征运输单的单仓容量及一次战利品撤离；房主确认成功的发运者取得物资；发运时重判守军、复苏、增援和关系 |
| 人员与库存 | 只运输本人雇员；保护物品沿原有预占与唯一运输事务结算，不能提前装备、消耗或重复领取；公共/本人库存运输不额外消耗搜刮机会；取物资格拒绝时不先启动战斗计时 |
| 离线与时间 | 离线雇员采用倒地保护；默认战斗加搜刮共用 10 分钟，地块冷却 60 分钟；房间有效现实时间计时，暂停停表、续开继续 |

工作权限、物品保护与战斗搜刮分别在实际原生入口接线，不通过修改游戏本体实现。

## 房主配置

- 全局设置和新建世界页增加袭击总时限及冷却输入。
- 总时限范围 1～120 分钟，默认 10；冷却范围 0～1440 分钟，默认 60。
- 总时限包括战斗与搜刮，击倒守军不重置。
- 全局设置只修改未来新建世界的默认值；新世界保存自己的配置，已有世界续开保留原规则。旧数据缺少新字段时使用 10/60 默认值。
- 每场战斗锁定本场时限、冷却及原有实际出征载体容量，增援不增加额度、不重置计时。
