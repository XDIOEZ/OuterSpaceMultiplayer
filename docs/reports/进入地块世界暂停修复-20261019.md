# 进入地块导致世界暂停修复

## 交付范围

- 修复版本 V1.47，仅修改联机 MOD，保留已有混合工作区。
- 用户明确要求本轮打包、暂不安装；不运行测试、游戏、Play Mode 或跨机验收。

## 原因与修改

`BeginLocalMapLoad` 在房主加载原生地图时保存旧暂停状态、设置 `Paused=true` 并向全房间广播；`MultiplayerSession.Tick` 还在加载屏障处提前返回，停止世界推进及银河广播。仅删除暂停赋值不足以解除第二处阻塞。

两份 Session 文件移除加载时钟接管，让世界时间、在线舰队、银河广播和房间现实计时继续推进。房主手动暂停及真实原生故障锁继续有效。已有袭击计时只在未暂停时累加，封顶 600 秒；战果结算仍等安全边界。

加载 FIFO、模拟权就绪确认、原生地图保护、超时与断开流程保持；运输落地、离线结算、存档和地图/个人资产捕获仍等待加载完成。原生 Ground 日结和原生托管运输已有 Hook 阻止访问半初始化地图，本轮不改游戏适配接口。

## 已知边界

- 已授权玩家可继续本机模拟、航行和接收银河状态，但经房主确认的新命令、地图增量与个人资产事务仍可能在加载 FIFO 等待；本次不承诺所有操作无延迟。
- 若加载期间跨过游戏日界，原生 `AcrossDay_Ground` 会被地块保护跳过，世界日游标仍前进，当前没有该图繁荣度/奖励日结的补算游标；估值重算也在该原生入口。本轮不新增跨图收益补发机制，后续应独立处理此边界。
