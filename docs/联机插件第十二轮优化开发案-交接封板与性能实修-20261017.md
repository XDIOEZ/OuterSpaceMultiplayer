## 四、N12-03：客人舰队无法移动要定位到第一处断点

**正确性先于性能。** 真实加载同源 DLL 的房主和客人各进行一次原版舰队导航；客人只能操控自己舰队。按同 `CommandId` 检查：

`native.hook → native.route → session.submit → client.sent → host.received → host.native.begin/end → host.motion.armed → host.motion → client.result`。

判定分四种：

- 输入/发送阶段没有证据：查原版 Hook 与 `RouteFleetCommand`，不猜传输故障。
- 房主拒绝：读取具体所有权/暂停/舰战锁/路由拒绝理由；合法拒绝不算 BUG。
- 房主接受却 `host.motion` 未见改变：检查 `NativeGalaxy.TickPlayerFleets` 和原版 `MoveTo_Pos/MoveTo_UIPos`，注意“连续 120 次有效主机采样未变”**并非 120 秒或必然 BUG**。
- 房主发生真实位移但客端不显示：仅再查 `NativeFleetSynchronization`、`NativeRemoteFleetProxy` 和客端 `ApplyGalaxy` 的位姿表现，不改动房主运动逻辑。

**验收**：同/跨星系，房主与客人舰队各一次，暂停、战斗锁、断线冻结与重连都要记录；必须观察房主实际位置与客端画面一致、UID 不重复、离线不耗油。没有房主和客人**同一次**游戏日志及人工操作结果，此任务记“待实测”，不得宣称 BUG 已修。

## 六、N12-06：多人正确性和发布封板

| 场景 | 必须通过的游戏内验证 |
| --- | --- |
| 新建 / 继续 / 重连 | `WorldId + PlayerId` 资产独立，默认 4 名开局雇员只首次授予一次；Steam/TapTap 身份不串、旧存档不追补、新世界自定义配置有效 |
| 2D 同图 / 切换模拟者 | 同一地块仅一个有效模拟者；观测端看见人物、建筑、伤害、工作和库存实时更新；`AuthorityEpoch/Revision/CommitId` 不回退 |
| 冷/热图 / 错缓存 / 断线进入 | SEED 只管地形，真实实体/物资仍由房主权威恢复；坏 SHA 回全量、可靠 FIFO 与 native ready 保序 |
| 玩家舰队 / 关系 / 舰战 | 客人只控自己的舰队；离线原地冻结且不耗油；访客权限、战果、伤害/动画真实一致 |
| 运输 / 离线袭击 / 保存失败 | 攻方/守方只结算一次；袭击 10 分钟、冷却 60 分钟、一次撤离至多一仓；存档失败保留上一完整 `SaveGeneration`，不损害单机档 |

只有 **代码、纯逻辑、真实引用编译、三端打包、安装、游戏/跨机验收**六项各有独立证据，才允许填写完成。安装前须确认游戏已关闭、备份旧 MOD 包，之后只通过主仓库 `Sync-ModCopies.ps1` 更新 `mods/FreeWorldMultiplayer`；不修改本体、共享 Harmony 或用户原始存档，不强杀游戏，不擅自 `push`/发布工坊。
