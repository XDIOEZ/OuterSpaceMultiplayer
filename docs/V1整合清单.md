# V1 整合清单

2026-10-15。此表管理完整交付的代码接入范围，不代替游戏或跨机验收；不能只依据 DTO 或接口存在将功能标为完成。

| 需求 | 负责实现 | 必须接通的真实链路 |
| --- | --- | --- |
| MOD 启动与房间 UI | Entry | 原生启动器 → 运行组件 → 会话 → 游戏适配，不修改本体 Prefab |
| TCP 直连与 Steam 房间 | Transport | 创建/加入、邀请、收发、分片、断线及资源释放 |
| 新建隔离联机世界 | Core + Game | 原生母舰开局 → 独立联机存储 → 不读取单机档 |
| 独立个人资产与进度 | Core + Game | 各玩家真实母舰、资金、科技、任务查询及写入分别绑定 |
| 重连和首次资产去重 | Core + Game | 稳定身份 → 已存玩家记录 → 同一雇员和舰队，不重发开局资产 |
| 世界时间与 UID | Session + Game | 房主唯一世界推进、客户端地表隔离、全局 UID 分配 |
| 地块拥有与正式基地 | Core + Game | 占地原子提交、每人一个正式基地、托管资格 |
| 地表实时同步 | Session + Game | 输入路由 → 唯一模拟者 → 实时增量/检查点 → 副本展示，副本不再次伤害或生产 |
| 断线接管与冻结/托管 | Session + Game | 撤销旧任期 → 最新检查点 → 同图接管或正确冻结/托管 |
| 友好协作与权限 | Core + Game | 玩家两两关系 → 原生操作和自动任务准入 → 关系变化中止原任务 |
| 角色归属与离线留人 | Core + Game | 人物 UID 和所有者不因切图、离线、接管或运输而改变 |
| 地表战斗与离线保护 | Core + Game | 实际伤害 → 中立转敌对、友好禁止攻击、保护守军必倒地 |
| 离线袭击与运输 | Session + Game | 真实空投战场 → 十分钟 → 一次撤离且一仓容量 → 原子转移 → 六十分钟地块冷却 |
| 太空互见和离线冻结 | Session + Game | 房主银河业务 → 在线全舰队展示 → 离线舰队停止推进 |
| 可靠保存 | Core + Game | 真实原生状态 + MOD 元数据同代持久化、关键事务保存后确认 |
| 退出与崩溃恢复 | Core + Game | 原生保存拦截、最终检查点、最后完整代恢复、旧会话拒绝 |
| 分发与引用范围 | Build | 仅 MOD 输出、真实程序集引用记录、无本体 DLL 捆绑、默认不部署 |

代码整合、最终 P3 引用编译、打包及 `Project3/mods/FreeWorldMultiplayer` 安装已完成。实际入口、构建结果、安装范围和未运行项目见 [整合与安装记录](整合与安装记录.md)。本表保持完整需求范围；不将编译和安装结果等同于游戏运行验收。
