## 3. 主控的实际执行顺序

1. 逐模块拿到**负责人明确交接**以及完整修改背景：声明受影响的协议、存档、GameBridge/Session 接口、依赖和单独回滚点。
2. 主控核对每份待提交路径的差异、完整编译所需的其它未跟踪文件与许可证；仅选择性暂存本任务内容。**禁止 `git add -A`、`git reset`、`git clean` 或直接从运行副本倒灌**。
3. 所有模块均确认交接后从干净 Git 提交重新构建，重新执行 `tools/Audit-SourceClosure.ps1 -RequireGitClosure`；若失败，继续精确处理剩余文件。
4. 三端以正式 `Sync-ModCopies.ps1 -Target All -BuildOnly` 分别构建，检查 `BUILD-INFO.json` 同一 `SourceRevision`、正确 `ReferenceMode`，并保存独立任务哈希。
5. 再等待用户的**真实双端游戏日志**来决定地表/舰队下一项热点；完成多机正确性回归之前不宣称 F5-03～F5-06 全部完成，不以冻结快照代替可发布包。
