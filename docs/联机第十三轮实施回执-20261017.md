## 二、新增生产验收工具与真实回归

`tools/Inspect-ModCopyVersions.ps1`：

- 用主仓库真实构建输入的 SHA256 作期望源码指纹，针对三个**精确的本 MOD 安装目录**读取 `BUILD-INFO.json`、真实 `FreeWorldMultiplayer.dll` 的程序集版本、PE 信息版本与字节 SHA256；**不调用 `Assembly.Load`、不读取身份/存档/聊天、不启动游戏、不复制安装文件**。
- 区分 `matching-disk-source`、`stale-disk-source`、`inconsistent-copy`、`incomplete-copy`、`missing-copy`；缺失、跨平台混包、伪造元数据与损坏 JSON 都不会产生“已验证新版运行”的假结论。
- 若输出报告，**只允许写到主仓库被 Git 忽略的 `artifacts/` 下且不覆盖既有报告**；返回 `ActualRuntimeLoadVerified=false`。这个工具**只证明磁盘文件状态，不证明正在运行的游戏实际加载版本**，后者必须由双方游戏日志检查。

`tools/Test-Inspect-ModCopyVersions.ps1` 用**测试目录中的复制 DLL/伪造 JSON**而非真实安装目录，覆盖当前版、旧版、目标混装、伪造指纹、缺文件、坏 JSON、禁止覆盖报告及禁止写入 `artifacts` 以外等：
